# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/blog` (listado) y `/blog/[slug]` (template de nota) en Rooftop at Riverside, alimentados por el feed público de blogs del dashboard de RestoExp.

**Architecture:** Una capa pura (`src/lib/blog-format.ts`) convierte cada nota del feed en un `Post` limpio: sin guiones medios, con portada validada, extracto y minutos de lectura. Una capa de fetch (`src/lib/blog.ts`) lee el feed con el caché de Next (`revalidate: 600`, tags `restoexp` y `blog`). Las dos páginas son Server Components que reusan `PlateHero`, `Section`, `Heading`, `FindUs` y `pageMeta`.

**Tech Stack:** Next 16.3 App Router, React 19.2, Tailwind 4, TypeScript. Tests con `node:test` (Node 24, que ya saca los tipos solo).

**Spec:** `docs/superpowers/specs/2026-09-23-blog-design.md`

## Global Constraints

- Se trabaja en `main`. **Hay otra sesión con archivos sin commitear en este repo** (formularios, `mail.ts`, `next.config.ts`, `not-found.tsx`). No tocarlos y no hacer `git add -A`: cada commit agrega sus archivos por nombre.
- No correr Prettier. Respetar el formato del archivo que se edita.
- Nunca un guion medio (`—`) en texto visible, ni en el copy propio ni en el que viene del feed.
- CTAs de una sola línea en todos los anchos.
- Interpárrafo de 12px o menos, siempre menor que titular→bajada (`gap-bajada`).
- Mobile nunca pasa de 16px de gutter. Los valores escalan en varios escalones, no en dos.
- El `h1` de la nota va **monocromo**. El `h1` del listado lleva su palabra en color (`titleAccent` de `PlateHero`).
- La nota va sin placa y sin esquinas inversas: portada rectangular.
- La condensada (`font-display`) nunca por debajo de 24px. Los títulos de card van con `role="card"` (Jost).
- La base nunca tumba una página, salvo la nota: si el feed falla, **la nota** da 500 y **el listado** muestra el estado vacío.
- Nunca usar `SUPABASE_SERVICE_ROLE_KEY`.
- Id del restaurante: `BLOG_RESTAURANT_ID || NEXT_PUBLIC_SUPABASE_RESTAURANT_ID`. Origen: `BLOG_FEED_ORIGIN || 'https://app.restoexp.com'`.
- Host de portada permitido: `https://kqibgbvdgxrjhdyfoxvm.supabase.co/storage/v1/object/public/restaurant-assets/`.

## Review Focus

1. **Guion medio dentro de un atributo o de `<code>`.** Tiene que quedar intacto; sólo se limpia el texto visible. Test en Task 1.
2. **Espacios alrededor de etiquetas inline.** `a <strong>b</strong> — c` no puede perder el espacio entre palabras al limpiar el guion. Test en Task 1.
3. **Nota con portada de ruta relativa** (así vienen las de Yava: `/images/blog/x.webp`). Tiene que salir sin foto, sin 404 de imagen y sin error de `next/image`. Test en Task 1.
4. **Slug repetido o vacío en el feed.** Se descarta el vacío y gana la primera aparición del repetido. Test en Task 1.
5. **`publishedAt` ausente o como ISO completo.** La fecha no se corre de día por zona horaria y no se dibuja " · 3 min read" con el separador colgando. Test en Task 1.

```js
import { registerHooks } from 'node:module';
import path from 'node:path';
import { pathToFileURL } from 'node:url';

/**
 * Sólo para `npm test`. Next resuelve `./restoexp` y `@/lib/x` solo; Node no.
 * Este hook le enseña las dos cosas: el alias `@/` apunta a `src/`, y un import
 * relativo sin extensión prueba con `.ts`.
 */
const SRC = pathToFileURL(path.resolve('src') + path.sep).href;

registerHooks({
  resolve(specifier, context, nextResolve) {
    const spec = specifier.startsWith('@/') ? SRC + specifier.slice(2) : specifier;
    try {
      return nextResolve(spec, context);
    } catch (error) {
      if (/^(\.|file:)/.test(spec) && !/\.[cm]?[jt]sx?$/.test(spec)) {
        return nextResolve(`${spec}.ts`, context);
      }
      throw error;
    }
  },
});
```

En `package.json`, dentro de `"scripts"` y después de `"start"`:

```ts
import { sinEmDash } from './restoexp';

/**
 * El blog, en su parte pura: del feed del dashboard a lo que dibuja el sitio.
 *
 * Sin fetch y sin Next, para que se pruebe con `npm test`. El fetch vive en
 * `blog.ts`.
 *
 * ⚠️ EL FEED ES EL MISMO DE PRETTY HENS, SANTA MARIA, YAVA Y JUANITOS:
 * `app.restoexp.com/api/public/restaurants/<id>/blogs`. Lo que cambia acá es
 * lo que se corrigió de ellos en la auditoría del 2026-09-23 (ver el spec):
 * la portada se valida contra el `remotePattern`, el extracto de respaldo sale
 * del HTML y no del markdown, y el texto pasa por `sinEmDash`, porque las notas
 * reales traen guiones medios y la regla del sitio no los admite.
 */

export interface FeedPost {
  readonly id: string;
  readonly slug: string | null;
  readonly canonicalUrl?: string | null;
  readonly title: string | null;
  readonly excerpt?: string | null;
  readonly coverImageUrl?: string | null;
  readonly coverImageAlt?: string | null;
  readonly ogImage?: string | null;
  readonly ogTitle?: string | null;
  readonly ogDescription?: string | null;
  /** Markdown. Sólo se usa si no vino `contentHtml`. */
  readonly content?: string | null;
  /** Ya sanitizado por el dashboard. Es lo que se imprime. */
  readonly contentHtml?: string | null;
  readonly jsonLd?: unknown;
  readonly author?: { readonly name?: string | null; readonly avatarUrl?: string | null } | null;
  /** YYYY-MM-DD. */
  readonly publishedAt?: string | null;
  /** ISO. */
  readonly updatedAt?: string | null;
  readonly featured?: boolean | null;
}

export interface Post {
  readonly slug: string;
  readonly title: string;
  readonly excerpt: string;
  readonly image: string | null;
  readonly imageAlt: string;
  /** YYYY-MM-DD o ''. */
  readonly publishedAt: string;
  /** ISO o ''. */
  readonly modifiedAt: string;
  readonly readMinutes: number;
  readonly featured: boolean;
}

export interface PostFull extends Post {
  readonly html: string;
  readonly metaTitle: string;
  readonly metaDescription: string;
  readonly ogImage: string | null;
  /** `/blog/<slug>`, o el path del canonical del dashboard si es de nuestro dominio. */
  readonly canonicalPath: string;
  readonly faqJsonLd: readonly Record<string, unknown>[];
}

/**
 * ⚠️ ES EL `remotePattern` DE `next.config.ts`, y tiene que seguir siéndolo.
 * Una portada con otro host tira `next/image` en runtime y se lleva el listado
 * entero: es lo que le pasa hoy a Santa Maria. Las de Yava vienen como ruta
 * relativa a SU `public/`, que acá daría 404.
 */
export const IMAGE_ORIGIN =
  'https://kqibgbvdgxrjhdyfoxvm.supabase.co/storage/v1/object/public/restaurant-assets/';

export function safeImage(url: string | null | undefined): string | null {
  return url && url.startsWith(IMAGE_ORIGIN) ? url : null;
}

const ENTIDADES: Record<string, string> = {
  '&amp;': '&',
  '&lt;': '<',
  '&gt;': '>',
  '&quot;': '"',
  '&#39;': "'",
  '&apos;': "'",
  '&nbsp;': ' ',
  '&mdash;': '—',
  '&#8212;': '—',
  '&ndash;': '–',
  '&rsquo;': '’',
  '&lsquo;': '‘',
  '&rdquo;': '”',
  '&ldquo;': '“',
  '&hellip;': '…',
};

const decode = (t: string) => t.replace(/&[#a-z0-9]+;/gi, (e) => ENTIDADES[e.toLowerCase()] ?? e);

/** `sinEmDash` sin comerse los espacios de los bordes, que separan del tag vecino. */
function limpiarTexto(t: string): string {
  const texto = t.replace(/&mdash;|&#8212;/gi, '—');
  if (!texto.includes('—')) return texto;
  const [, antes, medio, despues] = texto.match(/^(\s*)([\s\S]*?)(\s*)$/)!;
  // «<strong>b</strong> — c» → «<strong>b</strong>: c»: si el texto ARRANCA
  // con el guion, los dos puntos se pegan al tag de la izquierda.
  return `${medio.startsWith('—') ? '' : antes}${sinEmDash(medio)}${despues}`;
}

/**
 * Limpia el HTML del cuerpo. Dos cosas, y sólo en el texto visible:
 *   · saca los guiones medios, texto por texto, nunca en atributos ni en
 *     `<code>`/`<pre>`;
 *   · baja los `h1` a `h2`: el `h1` de la página es el título de la nota.
 *
 * No sanitiza: el dashboard ya manda `contentHtml` sanitizado, y el respaldo
 * de markdown sale escapado de `markdownToHtml`.
 */
export function cleanHtml(html: string): string {
  let crudo = 0;
  return html
    .split(/(<[^>]*>)/g)
    .map((parte) => {
      if (parte.startsWith('<')) {
        if (/^<(code|pre)\b/i.test(parte)) crudo++;
        else if (/^<\/(code|pre)\s*>/i.test(parte)) crudo = Math.max(0, crudo - 1);
        return parte.replace(/^<(\/?)h1\b/i, '<$1h2');
      }
      return crudo > 0 ? parte : limpiarTexto(parte);
    })
    .join('');
}

export function htmlToText(html: string): string {
  return decode(html.replace(/<[^>]*>/g, ' ')).replace(/\s+/g, ' ').trim();
}

const escapar = (t: string) =>
  t.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');

/**
 * Respaldo mientras el dashboard no mande `contentHtml` en todas las notas.
 * Párrafos y títulos, todo escapado. No es un parser de markdown y no quiere
 * serlo: los dos feeds reales de hoy ya traen el HTML.
 */
export function markdownToHtml(md: string): string {
  return md
    .split(/\n\s*\n/)
    .map((bloque) => bloque.trim())
    .filter(Boolean)
    .map((bloque) => {
      const titulo = bloque.match(/^#{1,6}\s+(.*)$/);
      if (titulo) return `<h2>${escapar(titulo[1].trim())}</h2>`;
      return `<p>${escapar(bloque.replace(/\s*\n\s*/g, ' '))}</p>`;
    })
    .join('');
}

export function readMinutes(text: string): number {
  const palabras = text.split(/\s+/).filter(Boolean).length;
  return Math.max(1, Math.round(palabras / 230));
}

function ymd(value: string | null | undefined): string {
  const m = value?.match(/^(\d{4}-\d{2}-\d{2})/);
  return m ? m[1] : '';
}

/** «April 15, 2026». En UTC al mediodía: nunca se corre de día. */
export function formatDate(value: string): string {
  const d = ymd(value);
  if (!d) return '';
  return new Date(`${d}T12:00:00Z`).toLocaleDateString('en-US', {
    month: 'long',
    day: 'numeric',
    year: 'numeric',
    timeZone: 'UTC',
  });
}

/** La línea de datos de la nota: «April 15, 2026 · 6 min read». */
export function postMeta(post: Post): string {
  return [formatDate(post.publishedAt), `${post.readMinutes} min read`].filter(Boolean).join(' · ');
}

/** Los nodos `FAQPage` del schema del dashboard, cada uno con su `@context`. */
export function faqNodes(jsonLd: unknown): Record<string, unknown>[] {
  const nodos = Array.isArray(jsonLd) ? jsonLd : jsonLd && typeof jsonLd === 'object' ? [jsonLd] : [];
  const out: Record<string, unknown>[] = [];
  for (const nodo of nodos) {
    if (!nodo || typeof nodo !== 'object') continue;
    const o = nodo as Record<string, unknown>;
    const contexto = o['@context'] ?? 'https://schema.org';
    const lista = Array.isArray(o['@graph']) ? (o['@graph'] as unknown[]) : [o];
    for (const g of lista) {
      if (!g || typeof g !== 'object') continue;
      const { '@context': _ctx, ...resto } = g as Record<string, unknown>;
      if (resto['@type'] === 'FAQPage') out.push({ '@context': contexto, ...resto });
    }
  }
  return out;
}

const humanize = (slug: string) =>
  slug
    .split(/[-_]+/)
    .filter(Boolean)
    .map((w) => w.charAt(0).toUpperCase() + w.slice(1))
    .join(' ');

function recortar(texto: string, max = 160): string {
  if (texto.length <= max) return texto;
  const corte = texto.slice(0, max);
  const espacio = corte.lastIndexOf(' ');
  return `${(espacio > 0 ? corte.slice(0, espacio) : corte).replace(/[\s.,;:]+$/, '')}…`;
}

const limpio = (t: string | null | undefined) => (t ? sinEmDash(t.trim()) : '');

export function toPostFull(feed: FeedPost, siteUrl: string): PostFull | null {
  const slug = feed.slug?.trim();
  if (!slug) return null;

  const html = cleanHtml(
    feed.contentHtml?.trim() ? feed.contentHtml : markdownToHtml(feed.content ?? ''),
  );
  const texto = htmlToText(html);
  const title = limpio(feed.title) || humanize(slug);
  const excerpt = limpio(feed.excerpt) || recortar(texto);
  const image = safeImage(feed.coverImageUrl);

  const canonical = feed.canonicalUrl?.trim() ?? '';
  const canonicalPath =
    canonical.startsWith(`${siteUrl}/`) ? canonical.slice(siteUrl.length) : `/blog/${slug}`;

  return {
    slug,
    title,
    excerpt,
    image,
    imageAlt: limpio(feed.coverImageAlt) || title,
    publishedAt: ymd(feed.publishedAt),
    modifiedAt: feed.updatedAt?.trim() ?? '',
    readMinutes: readMinutes(texto),
    featured: feed.featured === true,
    html,
    metaTitle: limpio(feed.ogTitle) || title,
    metaDescription: limpio(feed.ogDescription) || excerpt,
    ogImage: safeImage(feed.ogImage) ?? image,
    canonicalPath,
    faqJsonLd: faqNodes(feed.jsonLd),
  };
}

/** El feed entero, en su orden, sin notas vacías ni slugs repetidos. */
export function toPosts(feed: readonly FeedPost[], siteUrl: string): PostFull[] {
  const vistos = new Set<string>();
  const out: PostFull[] = [];
  for (const f of feed) {
    const p = toPostFull(f, siteUrl);
    if (!p || vistos.has(p.slug)) continue;
    vistos.add(p.slug);
    out.push(p);
  }
  return out;
}

/** La nota grande del listado: la marcada en el dashboard, o la primera. */
export function splitFeatured<T extends Post>(posts: readonly T[]): { featured: T | null; rest: T[] } {
  if (posts.length === 0) return { featured: null, rest: [] };
  const i = Math.max(0, posts.findIndex((p) => p.featured));
  return { featured: posts[i], rest: posts.filter((_, j) => j !== i) };
}
```

```ts
/**

 * Santa Maria, Yava y Juanitos. No pide clave y ya viene filtrado a lo

 * y los tags `restoexp` y `blog`. Una nota nueva aparece sola en ese plazo.

 * cargada hay que borrar esa carpeta y reiniciar.
 *
 * ⚠️ `BLOG_RESTAURANT_ID` ES SÓLO PARA VERIFICAR. Rooftop tiene 0 notas al
 * 2026-09-23; con ese override se levanta el dev con las de otro restaurante.
 * No va al `.env` de producción.

const FEED_ORIGIN = process.env.BLOG_FEED_ORIGIN || 'https://app.restoexp.com';
const RESTAURANT_ID =
  process.env.BLOG_RESTAURANT_ID || process.env.NEXT_PUBLIC_SUPABASE_RESTAURANT_ID;

const readFeed = cache(async (): Promise<readonly PostFull[]> => {
  if (!RESTAURANT_ID) {
    throw new Error('[blog] falta NEXT_PUBLIC_SUPABASE_RESTAURANT_ID, el feed no se puede pedir');
  }
  const url = `${FEED_ORIGIN}/api/public/restaurants/${RESTAURANT_ID}/blogs`;
  const res = await fetch(url, {
    headers: { accept: 'application/json' },
    next: { revalidate: 600, tags: ['restoexp', 'blog'] },
  });
  if (!res.ok) throw new Error(`[blog] el feed respondió ${res.status} (${url})`);
  const body = (await res.json()) as { data?: unknown };
  if (!Array.isArray(body?.data)) throw new Error(`[blog] el feed no devolvió { data: [...] } (${url})`);
  return toPosts(body.data as FeedPost[], SITE_URL);
});

/**
 * Para el listado y el sitemap. NUNCA TIRA: si el feed no contesta, el listado
 * muestra su estado vacío, como toda lectura de la base en este sitio.
 */
export async function getPosts(): Promise<readonly PostFull[]> {
  try {
    return await readFeed();
  } catch (error) {
    console.error(error instanceof Error ? error.message : error);
    return [];
  }
}

/**
 * Para la nota. ⚠️ SÍ TIRA si el feed falla: la página da 500 y no 404. Un 404
 * le diría a Google que borre una URL indexada por una caída de diez minutos.
 * `null` significa que el feed contestó y la nota no está.
 */
export async function getPost(slug: string): Promise<PostFull | null> {
  return (await readFeed()).find((p) => p.slug === slug) ?? null;
}

export async function getPostSlugs(): Promise<string[]> {
  return (await getPosts()).map((p) => p.slug);
}
```

## Task 5: Template de nota `/blog/[slug]`

**Files:**
- Create: `src/app/blog/[slug]/page.tsx`

**Interfaces:**
- Consumes: `getPost`, `getPosts`, `getPostSlugs` (Task 2). `postMeta`, `PostFull` (Task 1). `PostCard`, `Breadcrumbs`, `.prose-post` (Task 3). `pageMeta` con `article` (Task 2). `BRAND` de `@/lib/brand`.
- Produces: la ruta `/blog/[slug]`.

- [ ] **Step 1: `src/app/blog/[slug]/page.tsx`**

```tsx
import type { Metadata } from 'next';
import Image from 'next/image';
import { notFound } from 'next/navigation';
import PostCard from '@/components/blog/PostCard';
import FindUs from '@/components/sections/FindUs';
import Breadcrumbs from '@/components/shared/Breadcrumbs';
import { ArrowLink } from '@/components/shared/Button';
import Section from '@/components/shared/Section';
import { SectionHead } from '@/components/shared/Type';
import { getPost, getPosts, getPostSlugs } from '@/lib/blog';
import { postMeta, type PostFull } from '@/lib/blog-format';
import { BRAND } from '@/lib/brand';
import { SITE_URL, breadcrumbJsonLd, jsonLdScript, pageMeta } from '@/lib/seo';

export const revalidate = 600;
/** Una nota publicada después del build se genera en su primer pedido. */
export const dynamicParams = true;

export async function generateStaticParams() {
  return (await getPostSlugs()).map((slug) => ({ slug }));
}

type Props = { readonly params: Promise<{ slug: string }> };

export async function generateMetadata({ params }: Props): Promise<Metadata> {
  const { slug } = await params;
  const post = await getPost(slug);
  if (!post) return {};
  const cover = post.ogImage;
  return pageMeta({
    title: post.metaTitle,
    description: post.metaDescription,
    path: post.canonicalPath,
    ...(cover ? { image: { url: cover, alt: post.imageAlt } } : {}),
    article: {
      ...(post.publishedAt ? { publishedTime: post.publishedAt } : {}),
      ...(post.modifiedAt ? { modifiedTime: post.modifiedAt } : {}),
    },
  });
}

function postSchema(post: PostFull) {
  const url = `${SITE_URL}${post.canonicalPath}`;
  const casa = { '@type': 'Organization', name: BRAND.name, url: SITE_URL };
  return {
    '@context': 'https://schema.org',
    '@type': 'BlogPosting',
    '@id': `${url}#post`,
    headline: post.title,
    description: post.metaDescription,
    url,
    mainEntityOfPage: url,
    ...(post.image ? { image: [post.image] } : {}),
    ...(post.publishedAt ? { datePublished: post.publishedAt } : {}),
    ...(post.modifiedAt || post.publishedAt ? { dateModified: post.modifiedAt || post.publishedAt } : {}),
    // ⚠️ EL AUTOR ES LA CASA. El feed trae «Resto Experience», que es la
    // agencia, y en el sitio del cliente no va ni visible ni en el schema.
    author: casa,
    publisher: casa,
  };
}

/**
 * `/blog/[slug]` — el template de una nota.
 *
 * ══════════════════════════════════════════════════════════════════════════
 * ⚠️ SIN PLACA Y SIN ESQUINAS INVERSAS, A PROPÓSITO. Camila, 2026-09-23: «para
 * cada nota pondremos la imagen y el título sin el juego de recorte, la usaremos
 * más común». Cabecera sobre blanco, portada rectangular debajo, cuerpo a
 * medida de lectura.
 *
 * ⚠️ EL `h1` VA MONOCROMO, excepción explícita a la regla de la palabra en
 * color: el título viene del dashboard y no se puede elegir la palabra a mano.
 * Camila: «en blog pongamos monocromo».
 * ══════════════════════════════════════════════════════════════════════════
 */
export default async function PostPage({ params }: Props) {
  const { slug } = await params;
  const post = await getPost(slug);
  if (!post) notFound();

  const others = (await getPosts()).filter((p) => p.slug !== post.slug).slice(0, 3);
  const trail = [
    { name: 'Blog', path: '/blog' },
    { name: post.title, path: `/blog/${post.slug}` },
  ];

  return (
    <>
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{
          __html: jsonLdScript([postSchema(post), breadcrumbJsonLd(trail), ...post.faqJsonLd]),
        }}
      />

      <article aria-labelledby="post-title">
        <Section tone="paper" bandTop="md" bandBottom="none">
          <header className="mx-auto max-w-[52rem]">
            <Breadcrumbs crumbs={trail} className="mb-[20px]" />
            <p className="eyebrow text-deep">{postMeta(post)}</p>
            <h1
              id="post-title"
              className="mt-gap-kicker font-display text-h2 font-semibold uppercase text-ink"
            >
              {post.title}
            </h1>
            {post.excerpt ? <p className="bajada mt-gap-bajada text-lead">{post.excerpt}</p> : null}
          </header>

          {post.image ? (
            <div className="relative mt-bloque aspect-4/3 overflow-hidden rounded-image bg-bone md:aspect-video">
              <Image
                src={post.image}
                alt={post.imageAlt}
                fill
                priority
                sizes="(min-width: 1280px) 1280px, 100vw"
                className="object-cover"
              />
            </div>
          ) : null}
        </Section>

        <Section tone="paper" bandTop="md" bandBottom="lg">
          {/* El HTML lo manda el dashboard ya sanitizado; el respaldo de
              markdown sale escapado de `markdownToHtml`. */}
          <div className="prose-post" dangerouslySetInnerHTML={{ __html: post.html }} />

          <div className="mx-auto mt-bloque max-w-[68ch] border-t border-fog pt-6">
            <ArrowLink href="/blog">Back to all stories</ArrowLink>
          </div>
        </Section>
      </article>

      {others.length > 0 ? (
        <Section tone="paper" bandTop="none" bandBottom="lg" labelledBy="more-stories">
          <SectionHead title="More stories" id="more-stories" level={2} />
          <div className="mt-bloque grid gap-6 sm:grid-cols-2 lg:grid-cols-3">
            {others.map((p) => (
              <PostCard key={p.slug} post={p} />
            ))}
          </div>
        </Section>
      ) : null}

      <FindUs />
    </>
  );
}
```

⚠️ Antes de correr, confirmar en `Section.tsx` que `bandTop`/`bandBottom` combinan como se usan acá (líneas 117-160): si `band` es obligatorio cuando se pasan los otros, pasar `band="md"`.

⚠️ `text-h2` en el `h1`: va de 40 a 88px. Si un título real de doce palabras rompe en seis renglones a 390px, bajar a `text-h3 md:text-h2`, que sigue siendo condensada por encima de 24px.
