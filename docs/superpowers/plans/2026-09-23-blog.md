# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/blog` (listing) and `/blog/[slug]` (post template) on Rooftop at Riverside, fed by the public blog feed of the RestoExp dashboard.

**Architecture:** A pure layer (`src/lib/blog-format.ts`) turns each post in the feed into a clean `Post`: no em dashes, with a validated cover, excerpt and reading minutes. A fetch layer (`src/lib/blog.ts`) reads the feed with Next's cache (`revalidate: 600`, tags `restoexp` and `blog`). Both pages are Server Components that reuse `PlateHero`, `Section`, `Heading`, `FindUs` and `pageMeta`.

**Tech Stack:** Next 16.3 App Router, React 19.2, Tailwind 4, TypeScript. Tests with `node:test` (Node 24, which strips types on its own).

**Spec:** `docs/superpowers/specs/2026-09-23-blog-design.md`

## Global Constraints

- Work happens on `main`. **There is another session with uncommitted files in this repo** (forms, `mail.ts`, `next.config.ts`, `not-found.tsx`). Don't touch them and don't run `git add -A`: each commit adds its files by name.
- Don't run Prettier. Respect the formatting of the file being edited.
- Never an em dash (`—`) in visible text, neither in our own copy nor in what comes from the feed.
- Single-line CTAs at every width.
- Paragraph gap of 12px or less, always smaller than headline→subhead (`gap-subhead`).
- Mobile never goes over a 16px gutter. Values scale across several steps, not two.
- The post's `h1` is **monochrome**. The listing's `h1` carries its word in color (`titleAccent` from `PlateHero`).
- The post has no plate and no inverted corners: rectangular cover.
- The condensed face (`font-display`) never below 24px. Card titles use `role="card"` (Jost).
- The database never takes a page down, except the post: if the feed fails, **the post** returns 500 and **the listing** shows the empty state.
- Never use `SUPABASE_SERVICE_ROLE_KEY`.
- Restaurant id: `BLOG_RESTAURANT_ID || NEXT_PUBLIC_SUPABASE_RESTAURANT_ID`. Origin: `BLOG_FEED_ORIGIN || 'https://app.restoexp.com'`.
- Allowed cover host: `https://kqibgbvdgxrjhdyfoxvm.supabase.co/storage/v1/object/public/restaurant-assets/`.

## Review Focus

1. **Em dash inside an attribute or inside `<code>`.** It has to stay intact; only visible text is cleaned. Test in Task 1.
2. **Spaces around inline tags.** `a <strong>b</strong> — c` must not lose the space between words when the dash is cleaned. Test in Task 1.
3. **Post with a relative-path cover** (that's how Yava's come: `/images/blog/x.webp`). It has to render without a photo, without an image 404 and without a `next/image` error. Test in Task 1.
4. **Repeated or empty slug in the feed.** The empty one is dropped and the first occurrence of the repeated one wins. Test in Task 1.
5. **`publishedAt` missing or as a full ISO.** The date doesn't shift a day due to time zone and " · 3 min read" is not drawn with a dangling separator. Test in Task 1.

- [ ] **Step 1: Create the resolution hook for the tests**

Node 24 runs `.ts` without a flag, but it doesn't resolve extensionless imports or the `@/` alias. This hook adds both, only for the tests.

`scripts/test-hooks.mjs`:

```js
import { registerHooks } from 'node:module';
import path from 'node:path';
import { pathToFileURL } from 'node:url';

/**
 * Only for `npm test`. Next resolves `./restoexp` and `@/lib/x` on its own; Node doesn't.
 * This hook teaches it both things: the `@/` alias points to `src/`, and an
 * extensionless relative import tries `.ts`.
 */
const SRC = pathToFileURL(path.resolve('src') + path.sep).href;

registerHooks({
  resolve(specifier, context, nextResolve) {
    const spec = specifier.startsWith('@/') ? SRC + specifier.slice(2) : specifier;
    try {
      return nextResolve(spec, context);
    } catch (error) {
      if (/^(\.|file:)/.test(spec) && !/\.[cm]?[jt]sx?$/.test(spec)) {
        return nextResolve(`${spec}.ts`, context);
      }
      throw error;
    }
  },
});
```

In `package.json`, inside `"scripts"` and after `"start"`:


```ts
import { withoutEmDash } from './restoexp';

/**
 * The blog, in its pure part: from the dashboard feed to what the site draws.
 *
 * No fetch and no Next, so it can be tested with `npm test`. The fetch lives in
 * `blog.ts`.
 *
 * ⚠️ THE FEED IS THE SAME ONE AS PRETTY HENS, SANTA MARIA, YAVA AND JUANITOS:
 * `app.restoexp.com/api/public/restaurants/<id>/blogs`. What changes here is
 * what was fixed in them during the 2026-09-23 audit (see the spec):
 * the cover is validated against the `remotePattern`, the fallback excerpt comes
 * from the HTML and not from the markdown, and the text goes through `withoutEmDash`, because the
 * real posts carry em dashes and the site rule doesn't allow them.
 */

export interface FeedPost {
  readonly id: string;
  readonly slug: string | null;
  readonly canonicalUrl?: string | null;
  readonly title: string | null;
  readonly excerpt?: string | null;
  readonly coverImageUrl?: string | null;
  readonly coverImageAlt?: string | null;
  readonly ogImage?: string | null;
  readonly ogTitle?: string | null;
  readonly ogDescription?: string | null;
  /** Markdown. Only used if `contentHtml` didn't come. */
  readonly content?: string | null;
  /** Already sanitized by the dashboard. It's what gets printed. */
  readonly contentHtml?: string | null;
  readonly jsonLd?: unknown;
  readonly author?: { readonly name?: string | null; readonly avatarUrl?: string | null } | null;
  /** YYYY-MM-DD. */
  readonly publishedAt?: string | null;
  /** ISO. */
  readonly updatedAt?: string | null;
  readonly featured?: boolean | null;
}

export interface Post {
  readonly slug: string;
  readonly title: string;
  readonly excerpt: string;
  readonly image: string | null;
  readonly imageAlt: string;
  /** YYYY-MM-DD or ''. */
  readonly publishedAt: string;
  /** ISO or ''. */
  readonly modifiedAt: string;
  readonly readMinutes: number;
  readonly featured: boolean;
}

export interface PostFull extends Post {
  readonly html: string;
  readonly metaTitle: string;
  readonly metaDescription: string;
  readonly ogImage: string | null;
  /** `/blog/<slug>`, or the path of the dashboard canonical if it's on our domain. */
  readonly canonicalPath: string;
  readonly faqJsonLd: readonly Record<string, unknown>[];
}

/**
 * ⚠️ IT IS THE `remotePattern` FROM `next.config.ts`, and it has to stay that way.
 * A cover on another host breaks `next/image` at runtime and takes the whole
 * listing down with it: that's what happens to Santa Maria today. Yava's come as a path
 * relative to THEIR `public/`, which here would 404.
 */
export const IMAGE_ORIGIN =
  'https://kqibgbvdgxrjhdyfoxvm.supabase.co/storage/v1/object/public/restaurant-assets/';

export function safeImage(url: string | null | undefined): string | null {
  return url && url.startsWith(IMAGE_ORIGIN) ? url : null;
}

const ENTITIES: Record<string, string> = {
  '&amp;': '&',
  '&lt;': '<',
  '&gt;': '>',
  '&quot;': '"',
  '&#39;': "'",
  '&apos;': "'",
  '&nbsp;': ' ',
  '&mdash;': '—',
  '&#8212;': '—',
  '&ndash;': '–',
  '&rsquo;': '’',
  '&lsquo;': '‘',
  '&rdquo;': '”',
  '&ldquo;': '“',
  '&hellip;': '…',
};

const decode = (t: string) => t.replace(/&[#a-z0-9]+;/gi, (e) => ENTITIES[e.toLowerCase()] ?? e);

/** `withoutEmDash` without eating the edge spaces, which separate it from the neighboring tag. */
function cleanText(t: string): string {
  const text = t.replace(/&mdash;|&#8212;/gi, '—');
  if (!text.includes('—')) return text;
  const [, before, middle, after] = text.match(/^(\s*)([\s\S]*?)(\s*)$/)!;
  // «<strong>b</strong> — c» → «<strong>b</strong>: c»: if the text STARTS
  // with the dash, the colon sticks to the tag on the left.
  return `${middle.startsWith('—') ? '' : before}${withoutEmDash(middle)}${after}`;
}

/**
 * Cleans the body HTML. Two things, and only in visible text:
 *   · removes em dashes, text node by text node, never in attributes or in
 *     `<code>`/`<pre>`;
 *   · demotes `h1`s to `h2`: the page's `h1` is the post title.
 *
 * It doesn't sanitize: the dashboard already sends sanitized `contentHtml`, and the
 * markdown fallback comes out escaped from `markdownToHtml`.
 */
export function cleanHtml(html: string): string {
  let raw = 0;
  return html
    .split(/(<[^>]*>)/g)
    .map((part) => {
      if (part.startsWith('<')) {
        if (/^<(code|pre)\b/i.test(part)) raw++;
        else if (/^<\/(code|pre)\s*>/i.test(part)) raw = Math.max(0, raw - 1);
        return part.replace(/^<(\/?)h1\b/i, '<$1h2');
      }
      return raw > 0 ? part : cleanText(part);
    })
    .join('');
}

export function htmlToText(html: string): string {
  return decode(html.replace(/<[^>]*>/g, ' ')).replace(/\s+/g, ' ').trim();
}

const escape = (t: string) =>
  t.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');

/**
 * Fallback while the dashboard doesn't send `contentHtml` on every post.
 * Paragraphs and headings, all escaped. It isn't a markdown parser and doesn't want
 * to be one: the two real feeds today already carry the HTML.
 */
export function markdownToHtml(md: string): string {
  return md
    .split(/\n\s*\n/)
    .map((block) => block.trim())
    .filter(Boolean)
    .map((block) => {
      const heading = block.match(/^#{1,6}\s+(.*)$/);
      if (heading) return `<h2>${escape(heading[1].trim())}</h2>`;
      return `<p>${escape(block.replace(/\s*\n\s*/g, ' '))}</p>`;
    })
    .join('');
}

export function readMinutes(text: string): number {
  const words = text.split(/\s+/).filter(Boolean).length;
  return Math.max(1, Math.round(words / 230));
}

function ymd(value: string | null | undefined): string {
  const m = value?.match(/^(\d{4}-\d{2}-\d{2})/);
  return m ? m[1] : '';
}

/** «April 15, 2026». In UTC at noon: it never shifts a day. */
export function formatDate(value: string): string {
  const d = ymd(value);
  if (!d) return '';
  return new Date(`${d}T12:00:00Z`).toLocaleDateString('en-US', {
    month: 'long',
    day: 'numeric',
    year: 'numeric',
    timeZone: 'UTC',
  });
}

/** The post's data line: «April 15, 2026 · 6 min read». */
export function postMeta(post: Post): string {
  return [formatDate(post.publishedAt), `${post.readMinutes} min read`].filter(Boolean).join(' · ');
}

/** The `FAQPage` nodes from the dashboard schema, each with its `@context`. */
export function faqNodes(jsonLd: unknown): Record<string, unknown>[] {
  const nodes = Array.isArray(jsonLd) ? jsonLd : jsonLd && typeof jsonLd === 'object' ? [jsonLd] : [];
  const out: Record<string, unknown>[] = [];
  for (const node of nodes) {
    if (!node || typeof node !== 'object') continue;
    const o = node as Record<string, unknown>;
    const context = o['@context'] ?? 'https://schema.org';
    const list = Array.isArray(o['@graph']) ? (o['@graph'] as unknown[]) : [o];
    for (const g of list) {
      if (!g || typeof g !== 'object') continue;
      const { '@context': _ctx, ...rest } = g as Record<string, unknown>;
      if (rest['@type'] === 'FAQPage') out.push({ '@context': context, ...rest });
    }
  }
  return out;
}

const humanize = (slug: string) =>
  slug
    .split(/[-_]+/)
    .filter(Boolean)
    .map((w) => w.charAt(0).toUpperCase() + w.slice(1))
    .join(' ');

function truncate(text: string, max = 160): string {
  if (text.length <= max) return text;
  const cut = text.slice(0, max);
  const space = cut.lastIndexOf(' ');
  return `${(space > 0 ? cut.slice(0, space) : cut).replace(/[\s.,;:]+$/, '')}…`;
}

const clean = (t: string | null | undefined) => (t ? withoutEmDash(t.trim()) : '');

export function toPostFull(feed: FeedPost, siteUrl: string): PostFull | null {
  const slug = feed.slug?.trim();
  if (!slug) return null;

  const html = cleanHtml(
    feed.contentHtml?.trim() ? feed.contentHtml : markdownToHtml(feed.content ?? ''),
  );
  const text = htmlToText(html);
  const title = clean(feed.title) || humanize(slug);
  const excerpt = clean(feed.excerpt) || truncate(text);
  const image = safeImage(feed.coverImageUrl);

  const canonical = feed.canonicalUrl?.trim() ?? '';
  const canonicalPath =
    canonical.startsWith(`${siteUrl}/`) ? canonical.slice(siteUrl.length) : `/blog/${slug}`;

  return {
    slug,
    title,
    excerpt,
    image,
    imageAlt: clean(feed.coverImageAlt) || title,
    publishedAt: ymd(feed.publishedAt),
    modifiedAt: feed.updatedAt?.trim() ?? '',
    readMinutes: readMinutes(text),
    featured: feed.featured === true,
    html,
    metaTitle: clean(feed.ogTitle) || title,
    metaDescription: clean(feed.ogDescription) || excerpt,
    ogImage: safeImage(feed.ogImage) ?? image,
    canonicalPath,
    faqJsonLd: faqNodes(feed.jsonLd),
  };
}

/** The whole feed, in its order, without empty posts or repeated slugs. */
export function toPosts(feed: readonly FeedPost[], siteUrl: string): PostFull[] {
  const seen = new Set<string>();
  const out: PostFull[] = [];
  for (const f of feed) {
    const p = toPostFull(f, siteUrl);
    if (!p || seen.has(p.slug)) continue;
    seen.add(p.slug);
    out.push(p);
  }
  return out;
}

/** The big post on the listing: the one flagged in the dashboard, or the first. */
export function splitFeatured<T extends Post>(posts: readonly T[]): { featured: T | null; rest: T[] } {
  if (posts.length === 0) return { featured: null, rest: [] };
  const i = Math.max(0, posts.findIndex((p) => p.featured));
  return { featured: posts[i], rest: posts.filter((_, j) => j !== i) };
}
```

```ts
import { cache } from 'react';
import { toPosts, type FeedPost, type PostFull } from './blog-format';
import { SITE_URL } from './seo';

/**
 * The blog comes from the dashboard's PUBLIC FEED, the same one Pretty Hens,
 * Santa Maria, Yava and Juanitos read. It needs no key and already comes filtered to what's
 * published, with the featured one first and then from newest to oldest.
 *
 * ⚠️ IT IS NOT `no-store` LIKE IN THE SIBLING SITES. Rooftop caches every database
 * read with Next's cache (see `restoexp.ts`), and the blog too: 10 minutes
 * and the `restoexp` and `blog` tags. A new post shows up on its own within that window.
 * In dev the cache lives in `.next/cache/fetch-cache`: to see a freshly
 * loaded post you have to delete that folder and restart.
 *
 * ⚠️ `BLOG_RESTAURANT_ID` IS ONLY FOR VERIFYING. Rooftop has 0 posts as of
 * 2026-09-23; with that override dev starts up with another restaurant's posts.
 * It does not go in the production `.env`.
 */
const FEED_ORIGIN = process.env.BLOG_FEED_ORIGIN || 'https://app.restoexp.com';
const RESTAURANT_ID =
  process.env.BLOG_RESTAURANT_ID || process.env.NEXT_PUBLIC_SUPABASE_RESTAURANT_ID;

const readFeed = cache(async (): Promise<readonly PostFull[]> => {
  if (!RESTAURANT_ID) {
    throw new Error('[blog] NEXT_PUBLIC_SUPABASE_RESTAURANT_ID is missing, the feed cannot be requested');
  }
  const url = `${FEED_ORIGIN}/api/public/restaurants/${RESTAURANT_ID}/blogs`;
  const res = await fetch(url, {
    headers: { accept: 'application/json' },
    next: { revalidate: 600, tags: ['restoexp', 'blog'] },
  });
  if (!res.ok) throw new Error(`[blog] the feed responded ${res.status} (${url})`);
  const body = (await res.json()) as { data?: unknown };
  if (!Array.isArray(body?.data)) throw new Error(`[blog] the feed did not return { data: [...] } (${url})`);
  return toPosts(body.data as FeedPost[], SITE_URL);
});

/**
 * For the listing and the sitemap. IT NEVER THROWS: if the feed doesn't answer, the listing
 * shows its empty state, like every database read on this site.
 */
export async function getPosts(): Promise<readonly PostFull[]> {
  try {
    return await readFeed();
  } catch (error) {
    console.error(error instanceof Error ? error.message : error);
    return [];
  }
}

/**
 * For the post. ⚠️ IT DOES THROW if the feed fails: the page returns 500 and not 404. A 404
 * would tell Google to drop an indexed URL because of a ten-minute outage.
 * `null` means the feed answered and the post isn't there.
 */
export async function getPost(slug: string): Promise<PostFull | null> {
  return (await readFeed()).find((p) => p.slug === slug) ?? null;
}

export async function getPostSlugs(): Promise<string[]> {
  return (await getPosts()).map((p) => p.slug);
}
```

## Task 5: Post template `/blog/[slug]`

**Files:**
- Create: `src/app/blog/[slug]/page.tsx`

**Interfaces:**
- Consumes: `getPost`, `getPosts`, `getPostSlugs` (Task 2). `postMeta`, `PostFull` (Task 1). `PostCard`, `Breadcrumbs`, `.prose-post` (Task 3). `pageMeta` with `article` (Task 2). `BRAND` from `@/lib/brand`.
- Produces: the `/blog/[slug]` route.

- [ ] **Step 1: `src/app/blog/[slug]/page.tsx`**

```tsx
import type { Metadata } from 'next';
import Image from 'next/image';
import { notFound } from 'next/navigation';
import PostCard from '@/components/blog/PostCard';
import FindUs from '@/components/sections/FindUs';
import Breadcrumbs from '@/components/shared/Breadcrumbs';
import { ArrowLink } from '@/components/shared/Button';
import Section from '@/components/shared/Section';
import { SectionHead } from '@/components/shared/Type';
import { getPost, getPosts, getPostSlugs } from '@/lib/blog';
import { postMeta, type PostFull } from '@/lib/blog-format';
import { BRAND } from '@/lib/brand';
import { SITE_URL, breadcrumbJsonLd, jsonLdScript, pageMeta } from '@/lib/seo';

export const revalidate = 600;
/** A post published after the build is generated on its first request. */
export const dynamicParams = true;

export async function generateStaticParams() {
  return (await getPostSlugs()).map((slug) => ({ slug }));
}

type Props = { readonly params: Promise<{ slug: string }> };

export async function generateMetadata({ params }: Props): Promise<Metadata> {
  const { slug } = await params;
  const post = await getPost(slug);
  if (!post) return {};
  const cover = post.ogImage;
  return pageMeta({
    title: post.metaTitle,
    description: post.metaDescription,
    path: post.canonicalPath,
    ...(cover ? { image: { url: cover, alt: post.imageAlt } } : {}),
    article: {
      ...(post.publishedAt ? { publishedTime: post.publishedAt } : {}),
      ...(post.modifiedAt ? { modifiedTime: post.modifiedAt } : {}),
    },
  });
}

function postSchema(post: PostFull) {
  const url = `${SITE_URL}${post.canonicalPath}`;
  const org = { '@type': 'Organization', name: BRAND.name, url: SITE_URL };
  return {
    '@context': 'https://schema.org',
    '@type': 'BlogPosting',
    '@id': `${url}#post`,
    headline: post.title,
    description: post.metaDescription,
    url,
    mainEntityOfPage: url,
    ...(post.image ? { image: [post.image] } : {}),
    ...(post.publishedAt ? { datePublished: post.publishedAt } : {}),
    ...(post.modifiedAt || post.publishedAt ? { dateModified: post.modifiedAt || post.publishedAt } : {}),
    // ⚠️ THE AUTHOR IS THE VENUE. The feed brings «Resto Experience», which is the
    // agency, and on the client's site it goes neither visibly nor in the schema.
    author: org,
    publisher: org,
  };
}

/**
 * `/blog/[slug]` — the template for a post.
 *
 * ══════════════════════════════════════════════════════════════════════════
 * ⚠️ NO PLATE AND NO INVERTED CORNERS, ON PURPOSE. Camila, 2026-09-23: «for
 * each post we'll put the image and the title without the crop play, we'll use it
 * in a more standard way». Header on white, rectangular cover below, body at
 * reading measure.
 *
 * ⚠️ THE `h1` IS MONOCHROME, an explicit exception to the word-in-color
 * rule: the title comes from the dashboard and the word can't be picked by hand.
 * Camila: «on the blog let's go monochrome».
 * ══════════════════════════════════════════════════════════════════════════
 */
export default async function PostPage({ params }: Props) {
  const { slug } = await params;
  const post = await getPost(slug);
  if (!post) notFound();

  const others = (await getPosts()).filter((p) => p.slug !== post.slug).slice(0, 3);
  const trail = [
    { name: 'Blog', path: '/blog' },
    { name: post.title, path: `/blog/${post.slug}` },
  ];

  return (
    <>
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{
          __html: jsonLdScript([postSchema(post), breadcrumbJsonLd(trail), ...post.faqJsonLd]),
        }}
      />

      <article aria-labelledby="post-title">
        <Section tone="paper" bandTop="md" bandBottom="none">
          <header className="mx-auto max-w-[52rem]">
            <Breadcrumbs crumbs={trail} className="mb-[20px]" />
            <p className="eyebrow text-deep">{postMeta(post)}</p>
            <h1
              id="post-title"
              className="mt-gap-kicker font-display text-h2 font-semibold uppercase text-ink"
            >
              {post.title}
            </h1>
            {post.excerpt ? <p className="subhead mt-gap-subhead text-lead">{post.excerpt}</p> : null}
          </header>

          {post.image ? (
            <div className="relative mt-block aspect-4/3 overflow-hidden rounded-image bg-bone md:aspect-video">
              <Image
                src={post.image}
                alt={post.imageAlt}
                fill
                priority
                sizes="(min-width: 1280px) 1280px, 100vw"
                className="object-cover"
              />
            </div>
          ) : null}
        </Section>

        <Section tone="paper" bandTop="md" bandBottom="lg">
          {/* The dashboard sends the HTML already sanitized; the markdown
              fallback comes out escaped from `markdownToHtml`. */}
          <div className="prose-post" dangerouslySetInnerHTML={{ __html: post.html }} />

          <div className="mx-auto mt-block max-w-[68ch] border-t border-fog pt-6">
            <ArrowLink href="/blog">Back to all stories</ArrowLink>
          </div>
        </Section>
      </article>

      {others.length > 0 ? (
        <Section tone="paper" bandTop="none" bandBottom="lg" labelledBy="more-stories">
          <SectionHead title="More stories" id="more-stories" level={2} />
          <div className="mt-block grid gap-6 sm:grid-cols-2 lg:grid-cols-3">
            {others.map((p) => (
              <PostCard key={p.slug} post={p} />
            ))}
          </div>
        </Section>
      ) : null}

      <FindUs />
    </>
  );
}
```

⚠️ Before running, confirm in `Section.tsx` that `bandTop`/`bandBottom` combine the way they're used here (lines 117-160): if `band` is required when the others are passed, pass `band="md"`.

⚠️ `text-h2` on the `h1`: it goes from 40 to 88px. If a real twelve-word title breaks into six lines at 390px, drop to `text-h3 md:text-h2`, which is still condensed above 24px.
